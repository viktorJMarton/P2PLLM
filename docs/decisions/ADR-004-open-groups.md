# ADR-004 — Open peers first, closed groups later

Status: accepted design baseline, 2026-10-17.

## Decision
No assumption that independent node IDs mean noncolluding people. Membership interface is reserved; open network availability is best effort.

## Consequences
Implementation must reference this decision and provide evidence. Changes require a superseding ADR, never silent rewriting of history.
