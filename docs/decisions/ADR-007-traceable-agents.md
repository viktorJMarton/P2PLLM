# ADR-007 — Traceable role-based agent workflow

Status: accepted design baseline, 2026-10-17.

## Decision
One WORK/run lineage, concise journal, structured events, independent PR/security/math review. No fabricated test status or reasoning transcript.

## Consequences
Implementation must reference this decision and provide evidence. Changes require a superseding ADR, never silent rewriting of history.
