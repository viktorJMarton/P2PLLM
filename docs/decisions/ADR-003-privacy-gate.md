# ADR-003 — Fail closed on unavailable private compute

Status: accepted design baseline, 2026-10-17.

## Decision
Transport security and unintelligible activations are insufficient. Synthetic layer split is a lab, not public MVP. Profiles must define collusion/security assumptions.

## Consequences
Implementation must reference this decision and provide evidence. Changes require a superseding ADR, never silent rewriting of history.
