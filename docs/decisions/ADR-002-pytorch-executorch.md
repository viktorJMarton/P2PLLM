# ADR-002 — PyTorch development and ExecuTorch mobile path

Status: accepted design baseline, 2026-10-17.

## Decision
Replaces mandatory llama.cpp. Each export/training/backend claim must be demonstrated; private compute remains separate.

## Consequences
Implementation must reference this decision and provide evidence. Changes require a superseding ADR, never silent rewriting of history.
