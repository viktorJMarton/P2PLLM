# ADR-008 — Discover and measure available mobile accelerators

Status: accepted design baseline, 2026-10-17.

## Decision
NPU/GPU/DSP are candidates by backend/operator; ISP not general compute. No implied acceleration of MPC or training.

## Consequences
Implementation must reference this decision and provide evidence. Changes require a superseding ADR, never silent rewriting of history.
