## Superseded proposals
- Product-only/local-chat framing -> ecosystem and interoperable protocol.
- llama.cpp mandatory backend -> PyTorch + ExecuTorch; llama.cpp optional comparison.
- Plain layer splitting as public M1 success -> synthetic lab only, privacy is a hard MVP gate.
- Shared Rust core proves independent interoperability -> false; add independently written test peer.
- Knowledge-directory architecture as mandatory global service -> session capability layer with optional distributed discovery/index; no full-index broadcast.
- Always-on phone availability -> unsupported; explicit operating policy and churn handling.
- Uniform global active model -> local versioned models/adapters, exact composition agreement per shared session.
