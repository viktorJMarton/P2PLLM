# Decision meeting record

- **Meeting ID:** MEET-YYYYMMDD-NNN
- **Type:** Architecture Council / Engineering Sync / Red Team Review / Product Steering
- **Status:** proposed / held / no-decision / decision-pending-owner / accepted
- **Participants and mode:** Actual people or agents that demonstrably participated; if generated by one agent, say *single-agent proposal*
- **Related:** REQ- / WORK- / AUD- / RFC- / ADR-
- **Evidence:** Files, test output, issue/PR and revision (or *unavailable*)

## Trigger and question
State the concrete blocker, failed test, risk or opportunity. Why decide now?
