# Glossary
Node: independently operated runtime. Peer: another node. Session: authenticated logical association, possibly several streams. Task: bounded request. Step: ordered stateful computation within a task. Model composition: immutable base revision + tokenizer + export/quantization + adapter revisions. Privacy profile: locally trusted description of cryptographic assumptions/implementation, not a peer score. Adapter: versioned parameter-efficient update, not arbitrary executable code. Knowledge store: retrievable local information, not necessarily learned weights. Inference != tokenization != training. Transport encryption != protected computation. Reputation != correctness proof. NPU != ISP. Packet ID != NFT.
